# JBD BMS 管理工具

面向嘉佰达（JBD）智能 BMS 的 Android 只读监控工具。项目使用 Kotlin、Jetpack Compose 和 Android BLE，最低支持 Android 12（API 31）。

完整版本变化请查看 [CHANGELOG.md](CHANGELOG.md)。

## 当前功能

- 扫描附近 BLE 设备并优先标记可能的 JBD BMS
- 保存所有成功连接过的设备，打开 App 自动连接最后使用的设备，意外断线后按 2/5/10/30 秒退避重连
- 自动发现标准 `FF00/FF01/FF02`、兼容 `FFE0/FFE1` 及未知可写/通知特征
- 读取硬件型号、芯片方案、基本状态和单体电压
- 每秒刷新电池当前总电压、充放电电流、剩余容量、总安时、SOC、循环次数、温度、MOS 和保护状态
- 严格串行发送 BLE 命令，具备连接、写入和响应超时，避免慢速模块丢命令
- 超过 5 秒无有效响应时标记数据过期，超过 10 秒后自动重连，不把旧数据继续标成“实时”
- 自动探测经典 `DD…77` 和新版 `FF AA` 蓝牙认证，支持用户输入 6 位读取密码
- 在设置中展示设备地址、BLE 服务/特征、协议类型、V12 扩展、串数及软件版本，便于实机确认协议
- 显示单体最高/最低电压、压差和均衡状态
- 支持 V12 扩展状态中的满充容量与估算 SOH（设备返回时）
- 保存最后一次真实 BMS 状态，断开连接后仍可离线查看
- 右上角“设置”弹框集中展示型号、芯片方案、软件版本和通信信息
- 使用专门设计的电池、监测波形与 BMS 电路主题应用图标
- 同时打包 Android 自适应图标和五套传统 PNG 密度图标，兼容管理平台提取
- 未知设备保持只读，不修改保护参数、不控制 MOS

## 构建

```bash
./gradlew testDebugUnitTest assembleDebug
```

安装包生成在：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 自动发布安装包

发布新版本前，必须先在 `CHANGELOG.md` 中把“未发布”内容归档到对应版本号，并详细记录新增、优化、修复和移除内容。GitHub 发布流程会读取该版本的记录作为 Release 说明；缺少对应版本记录时会停止发布。

每次代码推送到 `main` 分支后，GitHub Actions 会自动执行单元测试、Lint 检查和 APK 构建，并在仓库的 **Releases** 页面创建一个新的测试版本。APK 使用固定的调试签名，可以直接覆盖安装前一个测试版本。

也可以在 GitHub 仓库的 **Actions → 构建并发布 APK → Run workflow** 中手动触发一次构建。

## 实机测试

1. 在 Android 12 或更高版本手机上安装 APK。
2. 打开应用并允许“附近设备”权限。
3. 点击“扫描附近的 BMS”，选择嘉佰达蓝牙设备。
4. 首次成功连接后，后续打开 App 会自动连接该设备；设备不在附近时会返回扫描页面。
5. 如果无法识别型号，可在“设置”中查看设备信息、BLE 通道和识别协议。

> 应用只开放状态读取与必要的蓝牙身份认证。电池保护参数、工厂模式和 MOS 控制功能均未开放。
